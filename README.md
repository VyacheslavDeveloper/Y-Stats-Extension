## Описание
Браузерное расширение, которое встраивается в консоль разработчика Яндекс Игр и показывает подробную статистику доходов, которой нет в стандартном интерфейсе.

### ✨ Возможности
* **Детальный доход:** Сумма по опубликованным играм выбранного аккаунта (до 100 игр). Если кабинет не вернул итог периода, виджет складывает доступные дневные значения и отмечает пропуски. Дни до известной первой публикации не считаются пропусками.
* **Разбивка источников:** Показывает рекламный доход и внутриигровые покупки (In-app), как действующий кабинет Яндекс Игр.
* **Гибкие периоды:** Можно выбрать конкретный день, 7/30 дней, текущий/прошлый месяц или доступный период (до 13 месяцев).
* **Удобная таблица:** Сортировка игр по доходу, числу игроков и доходу на 1 000 игроков. За период число игроков — сумма дневных значений. Звёздочкой отмечена сумма по доступным дням. Для дохода на 1 000 игроков звёздочка означает расчёт только по дням, за которые известны оба показателя.

## 🔒 Конфиденциальность и безопасность
* **Локальная работа:** Весь код выполняется **локально** в вашем браузере.
* **Никакого сбора данных:** Расширение **не отправляет** ваши токены, куки или статистику на сторонние серверы. Метрики запрашиваются в вашем кабинете. Чтобы узнать дату первой публикации, расширение отправляет публичные ID игр в каталог Яндекс Игр на `yandex.ru` без куки и токена. Для проверки версии оно читает публичный манифест проекта на GitHub.
* **Открытый код:** Исходный код полностью открыт. Вы можете проверить его перед установкой, чтобы убедиться в безопасности.

## 🛠 Установка

Установочный архив готов к использованию в настольном браузере.

1.  В разделе **Releases** этого репозитория откройте нужный выпуск и скачайте **Y-Stats-Extension.zip** из списка **Assets**. Распакуйте архив.
2.  Откройте в браузере адрес управления расширениями (например `chrome://extensions/`).
3.  В правом верхнем углу включите **переключатель** «Режим разработчика» (Developer mode).
4.  Нажмите кнопку **«Загрузить распакованное»** (Load unpacked).
5.  Выберите распакованную папку, в которой лежит `manifest.json`. При обновлении уже установленной копии замените файлы в её папке, перезагрузите расширение и обновите вкладку кабинета.

## 🚀 Как пользоваться

1.  Зайдите в консоль разработчика: [games.yandex.ru/console/applications](https://games.yandex.ru/console/applications).
2.  Дождитесь, пока над списком игр появится новый блок **«Статистика заработка»**.
3.  Нажмите кнопку **«Загрузить статистику»**.
4.  Дождитесь окончания загрузки (зеленый прогресс-бар).
5.  Выберите день или период в обзоре, таблице или на графике. Нажмите на строку состояния, чтобы увидеть пояснения о недоступных данных.
6.  После возврата в кабинет суммы скрыты. Для аккаунта с собственным числовым ID кеш действует до 10 минут в пределах отчётного дня. Если кабинет обозначает личный профиль как `-1`, кнопка загружает свежие данные при каждом открытии. **Показать** открывает сохранённые данные, **Обновить** запрашивает свежие. Когда кеш истекает, снова появляется **Загрузить статистику**.

## ℹ️ Важная информация
Так как расширение использует приватные API (Private Endpoints):
* Инструмент может временно перестать работать, если платформа обновит дизайн или структуру консоли.
* При большом количестве игр загрузка может занять некоторое время из-за ограничений браузера на частоту запросов.
